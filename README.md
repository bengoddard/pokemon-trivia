# pokemon-trivia

This is an application that you can use to play a trivia game all about pokemon.
You click a button, a pokemon appears, and you have to guess their name. There are also counters to keep track of your correct and incorrect guesses.

## SETUP INSTRUCTIONS
Run 'npm install'
Run 'npm run dev'

## API Used
- **PokéAPI**: Used the `https://pokeapi.co/api/v2/pokemon/{id}` endpoint to fetch species names and high-quality artwork.

## ENDPOINTS
Home: http://localhost:/
Game: http://localhost:/play
